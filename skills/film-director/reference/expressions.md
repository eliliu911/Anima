# 表情：用 FACS 动作单元写，而不是形容词

来源是 Higgsfield 技能库里的 `higgsfield-facs`
（[OSideMedia/higgsfield-ai-prompt-skill](https://github.com/OSideMedia/higgsfield-ai-prompt-skill)）。

**这一套是引擎无关的** —— FACS（Facial Action Coding System，Ekman）是心理学
标准，不是某个平台的私货，所以它在 H3 / SDXL / Z-Image 上同样成立。

## 为什么形容词不够

「眉头紧锁」「脸色阴沉」「强压着怒火」这类词，模型只能给一个**平均值** ——
它见过的「愤怒」照片里，眉毛、眼睑、嘴唇各种组合都有。

FACS 把脸拆成**互相独立的肌肉动作**（AU = Action Unit）。指定哪几个 AU 收缩、
哪几个**不动**，就把那个平均值收窄成一个具体的脸。

**最有用的往往是「哪个不动」** —— 很多情绪的定义就在于某一个 AU 缺席：

| 情绪 | 写法 | 要害 |
|:---|:---|:---|
| 真笑 | AU6（眼轮匝肌）+ AU12（嘴角上扬） | 两个都在 |
| **假笑 / 故作镇定** | AU12 在，**AU6 不动** | 眼睛不参与 —— 这就是假笑的定义 |
| 强压住的愤怒 | AU4（皱眉）+ AU7（眼睑紧绷）+ AU23（嘴唇紧绷）+ AU17（下巴上提） | 没有 AU12，也没有张嘴 |
| 爆发的愤怒 | AU4 + AU5（上眼睑提起）+ AU23 + AU25/26（张嘴） | AU5 和 AU7 是反的：一个瞪、一个眯 |
| 轻蔑 | AU14（单侧嘴角向后拉） | **单侧**是关键 |
| 惊愕 | AU1+AU2（内外眉都抬）+ AU5 + AU26（下巴下落） | 和愤怒共用 AU5，靠眉毛方向区分 |
| 隐忍的悲伤 | AU1（内眉抬）+ AU15（嘴角下垂）+ AU17 | AU1 只抬内侧 —— 这是悲伤和惊讶的分界 |

## 常用 AU 的中文说法

写进提示词时**两种都写**：AU 编号给结构，中文给模型理解（H3 的编码器是
Qwen3-VL，中文原生）。

| AU | 中文 |
|:---|:---|
| AU1 / AU2 | 内侧眉毛抬起 / 外侧眉毛抬起 |
| AU4 | 眉头向内下压（皱眉） |
| AU5 / AU7 | 上眼睑提起（瞪） / 眼睑收紧（眯） |
| AU6 | 眼周肌肉收缩，眼角出现笑纹 |
| AU9 | 鼻子皱起 |
| AU10 | 上唇提起 |
| AU12 / AU14 | 嘴角向上斜拉 / 嘴角向后拉（单侧＝轻蔑） |
| AU15 | 嘴角向下 |
| AU17 | 下巴向上顶 |
| AU23 / AU24 | 嘴唇收紧 / 双唇紧压 |
| AU25 / AU26 | 双唇分开 / 下颌下落 |
| AU43 | 闭眼 |

## 怎么写进提示词

```
他的脸：眉头向内下压、眼睑收紧（AU4 + AU7），嘴唇绷成一条线、下巴向上顶
（AU23 + AU17），嘴角没有任何上扬。
```

**不要只写编号** —— 「AU4 + AU7」对模型是两个陌生符号；也**不要只写中文** ——
那就退回形容词了。两个一起给，编号负责别漏、中文负责能懂。

## 尚未验证

**AU 码对 H3 到底有多少增益，没有做过对照。** 要验的话：同一张尾帧、
同一个 seed，一版写「眉头紧锁、脸色阴沉」，一版写 AU 码，并排看。
一张图几十秒到一百多秒，两张不到四分钟。

**验之前别把它当结论用。** 这一页是「有依据的候选做法」，不是实测过的规范。
