# 预告片 / 先导预告（Teaser）

做预告片时读这份。它不是「把一场戏拍成视频」—— 是一支**营销短片**：
先想清楚它要在观众那里起什么作用（留住、好奇、记住片名），再拆镜头。

> 来源：行业资料（见文末）+ 用户对《回收师》先行预告的要求（2026-09-26）。
> 第一版预告失败的原因就是没按这份做：竖屏、没有运镜设计、没用资产当参考、没出首尾帧、没有黑场和片尾。

## 1. 先分清是哪一种

| 类型 | 时长 | 结构 | 给多少剧情 |
|---|---|---|---|
| **先导预告 Teaser** | 15~90 秒 | **两幕**：一点点背景 → 一个招牌时刻（set-piece） | 几乎不给，只给「这部剧是什么感觉」 |
| 正式预告 Trailer | 1~2.5 分钟 | 冷开场 + 三幕 + 按钮 | 给世界观、冲突、高潮，**不给结局和大反转** |
| 投放短片 Spot | 15 / 30 秒 | 三幕压缩 | 5~7 秒内必须到一个有意思的时刻 |

15 秒的先行预告按 Teaser 做：**只卖一个钩子**，不讲故事。

## 2. 结构（正式预告的完整版，先导预告取其中几段）

1. **冷开场（Cold Open）**：一开场就是最刺激 / 最怪 / 最有冲突的画面，几乎不需要上下文就看得懂。
   短剧投放的「黄金三秒」是同一件事：**从冲突开场，不从铺垫开场**，第一个镜头就是动作进行中的瞬间。
2. **引入**：交代前提，最好用「一连串问题」而不是解释 —— 保留神秘感。
3. **升级**：对手 / 核心冲突出现，节奏加快。
4. **高潮**：最有冲击力的镜头快速连切，音乐推到顶，常常**不配台词**，让画面说话。
5. **标题卡**：高潮之后**硬切到标题**，前面通常有**一拍静音**。
6. **按钮（Button / Stinger）**：标题之后再来一句狠话、一个笑点或一个动作，收尾。

## 3. 节奏

- **快 — 慢 — 快**，不要一直快。一直高能量等于没有高能量。
- **压着再抬**：普通镜头故意不卡音乐点，关键镜头卡在重拍上，才显得重。
- **大时刻之前先抽空**：把音乐和声音压低甚至静音，再让声音猛地回来 —— 能量差才是冲击力。
- 音效只放在关键点；**有音效的地方不压台词，有台词的地方不压音效**。

## 4. 黑场、字卡、台词

- **黑场（dip / cut to black）**：切段落、给重要镜头加标点、制造停顿和不安。
  先导预告里场景之间用黑场切换，配合运镜，比硬切更紧张。
- **闪白 / 光晕**：强调冲击点；**快闪剪（flutter cut）**：堆紧张。
- **台词要短、要狠**，挑能单独成立的句子，不用长独白，不提前交代剧情。
  行业常规：几句台词拼在一起、多放在画外或背对镜头，画面和台词不必一一对应。
- **黑场上继续台词、用字幕接下去**：最后一句台词说到一半或说完后切黑，
  剩下的字 / 下一句以字幕出现在黑场上 —— 画面没了、信息还在，好奇心被吊住。
- 字卡（copy card）用来快速讲清故事或建立期待；字幕要跟台词、音乐节奏对齐。

## 5. 片尾（End Slate）

先导预告**干净地收在片名和日期上**，让观众记住一个名字：

- **剧名**（标题字设计）
- 上线时间 / 平台（有就写，「即将上线」也行）
- **出品方 / 版权信息**（© 年份 出品方）、必要时账号 / 话题
- 按钮镜头如果有，放在剧名之后、最后一两秒

## 6. 在这台机器上怎么做（AI 出片链路）

1. **画幅按项目走**，预告片一般 **16:9 或 21:9 宽屏**，更有冲击感。不要照搬竖屏设置。
2. **先出方案给用户确认**：每段几秒、景别、**运镜**（推 / 拉 / 摇 / 升降 / 环绕，逐段写清）、黑场位置、字幕内容、片尾。
3. **参考图用单张资产图**：角色的大脸 / 全身、场景图、道具图。**不要整张设定卡** —— 卡上的脸只有几十像素，H3 认不出（2026-09-26 实测翻车）。
4. **先出首帧（和需要的尾帧）**，看过画面对了再出视频；视频走首尾帧 / 参考生视频，不靠纯提示词。
5. **黑场、字幕、剧名、版权都在后期叠**（ffmpeg），不让视频模型写字 —— 模型写的字是乱码。
6. 出完**真的看、真的听**：逐秒抽帧看人物像不像；用 Whisper 转写音轨，确认没有模型自己编的杂音人声。

## 15 秒先行预告的一个骨架（照《回收师》的要求）

| 时间 | 内容 | 手法 |
|---|---|---|
| 0~3s | 钩子画面，动作进行中 | 冷开场，运镜推进 |
| 3~4s | 黑场 | 静音一拍 |
| 4~8s | 第二个场景 / 反应 | 运镜变化（摇 / 拉），声音回来 |
| 8~9s | 黑场 | 紧张 |
| 9~12s | 最后一句台词 | 说到关键处切黑 |
| 12~13s | 黑场 + 台词以字幕继续 | 吊好奇心 |
| 13~15s | 剧名 + 版权信息 | 干净收尾 |
